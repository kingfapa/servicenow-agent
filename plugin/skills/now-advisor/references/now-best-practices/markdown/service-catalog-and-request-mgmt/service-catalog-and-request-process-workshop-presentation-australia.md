## Slide 18

Key terms used in this workshop

Terminology

Catalog item - a product or service a user can request.

Record producer - a catalog item that creates a record on a target table.

Order guide - guides a user through ordering multiple related items.

Requested item (RITM) - tracks fulfilment of an ordered item.

Catalog task (SCTASK) - a fulfilment task for a requested item.

Multi-row variable set (MRVS) - captures multiple rows of input.

Catalog Builder - the guided, low-code experience for creating and maintaining catalog items.

12

### Speaker notes

Explain and discuss

Quick vocabulary check before we start - these terms come up throughout the workshop.

Catalog item - anything a user can request. Everything else here is either a type of catalog item or something one produces.

Record producer - a catalog item that creates a record on a target table instead of ordering a thing. Classic example: "Report an issue" creating an incident.

Order guide - walks a user through ordering several related items at once. Onboarding is the textbook case.

Requested item (RITM) - tracks fulfillment of an ordered item; this is what requesters and fulfillers watch for status.

Catalog task (SCTASK) - the actual unit of work under a RITM. One RITM can spawn several tasks.

Multi-row variable set (MRVS) - captures multiple rows of input, like five users each with a name and start date.

Catalog Builder - the guided, low-code experience for creating and maintaining items. That's where most of our build work happens.

The two most commonly mixed up: a record producer creates a record, an order guide bundles items. And RITM is what was asked for; SCTASK is what someone has to do about it.

### Speaker notes

Explain and discuss

Four metrics we recommend tracking once the catalog is live.

Time to fulfillment - how long each item takes to deliver. Track it per item, not just as an average, so you can see which ones are slow and whether you're meeting the delivery dates you advertise.

Frequency of request per item - a measure of popularity. Low volume can mean an item is no longer required; a spike often signals an underlying issue that needs resolving at source rather than more requests being fulfilled.

New catalog items delivered per month - an indicator of how accurate the catalog is and whether it's keeping pace with new services being offered.

Requests completed within agreed target times - both the number and the percentage. This is the SLA health check.

Taken together: the first two tell you how the existing catalog performs, the last two tell you whether it's growing and holding to its commitments. Set a baseline early, or you can't prove improvement later.
