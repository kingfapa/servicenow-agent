Now Assist panel

### Speaker notes

Explain

The now assist panel provides a natural language interface to access now assist features, similar to the experience with virtual agent. For compatible features, you can decide whether to enable the feature in product, in the Now Assist panel, or both.

In product will appear native to the core UI or workspace, at the time of need. For example for incident summarization, a ‘summarize’ UI action will appear at the top of the incident form, however you can also summarize an incident by opening the now assist panel and using natural language to request the incident be summarized.

Discuss

Would you like to use the now assist panel? What are the advantages/disadvantages to using either or both in your workflow?

Decision

Will you enable in-product/now assist panel or both in each Now Assist feature?
